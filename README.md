# rubric

A personal marketplace of opinionated development conventions for Claude Code.

`rubric` is the catalog. It hosts plugins: **engineering** and **blueprint**.

## Plugins

- **engineering** — opinionated engineering conventions as role-based skills (developer, QA, security, release).
- **blueprint** — co-author concise, decision-dense design specs with Claude, one abstraction at a time.

## Install

```
/plugin marketplace add branow/rubric
/plugin install engineering@rubric
/plugin install blueprint@rubric
```
